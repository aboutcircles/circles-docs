# Product Context

## Product Name

Circles

## Product Description

Circles is a decentralized protocol engineered to create and distribute fair, socially driven money through personal currencies. It is built on the principle that every person receives one Circle (CRC) every hour—unconditionally. Circles leverages smart contracts on the Gnosis Chain and depends on trust relationships between its users. The system supports personal, group, and organizational avatars, each accompanied by its own currency.

## Key Features

* **Personal Currencies:** Every user is issued a personal currency (CRC) that is continuously minted at a rate of 1 CRC per hour.
* **Group Currencies:** Groups have the capability to create and manage their own currencies.
* **Organization Avatars:** The protocol supports organizational entities within the ecosystem, enabling tailored financial interactions.
* **Trust Connections:** Transactions occur based on established trust relationships between users.
* **Demurrage:** Circles applies a daily demurrage at a rate equivalent to 7% per year, ensuring a dynamic and balanced currency supply.
* **ERC1155 Tokens:** The protocol is founded on the ERC1155 multi-token standard, supporting both personal and group avatars.
* **SDK Integration:** A comprehensive SDK allows developers seamless integration with the protocol.
* **Pathfinder Service:** An integrated service identifies optimal trust routes for efficient currency exchanges.

## Problems Solved

* **Fair Money Distribution:** Establishes a system where every individual receives a basic income in the form of personal currency.
* **Social Money:** Empowers communities to create their own currencies based on trust and shared values.
* **Economic Inclusion:** Provides accessible financial tools, eliminating traditional banking barriers.
* **Community Building:** Fosters economic cooperation and group formation by enabling trust-based interactions.
* **Developer Accessibility:** Simplifies the process for developers building on top of the Circles protocol.

## User Experience Goals

* Seamless and intuitive SDK integration for developers.
* Clear, detailed documentation accompanied by practical examples.
* Comprehensive presentation of all protocol features.
* Step-by-step tutorials and implementation guides that are easy to follow.
* Robust error handling and clear guides for debugging.
